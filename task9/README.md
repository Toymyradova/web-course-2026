# Задания 9 — Zen-Money (учёт финансов)

**Что сделано:**
- Реализовано полноценное CRUD-приложение для учёта финансов.
- **Часть 1 (Лаба 8):** Базовая работа с `json-server`: создание, чтение, обновление, удаление операций (POST, GET, PUT, DELETE). Подсчёт общего баланса. Разделение кода на ES-модули (`api.js`, `ui.js`, `main.js`).
- **Часть 2 (Лаба 9):** 
  - Фильтрация операций по типу (доход/расход), категории и диапазону дат.
  - Создание пользовательских категорий (форма + POST-запрос).
  - Сохранение выбранных фильтров в `localStorage` (настройки восстанавливаются при перезагрузке страницы).
  - Валидация формы (положительная сумма, обязательный выбор категории и даты) с подсветкой полей.
- Вся логика обёрнута в `async/await` и `try/catch`.

**Файлы:**
- `index.html` — разметка;
- `style.css` — стили;
- `db.json` — база данных для `json-server`;
- `api.js` — модуль работы с сервером;
- `ui.js` — модуль отрисовки интерфейса;
- `main.js` — точка входа, логика фильтров и событий.

**Как запустить локально:**
1. Установить `json-server`: `npm install -g json-server`
2. Перейти в папку с проектом и запустить сервер: 
   `json-server --watch db.json --port 3001`
3. Открыть `index.html` в браузере (через Live Server или просто открыть файл).
