# Task 2 — Адаптивный лендинг

**Что сделано:**
- Сверстан одностраничный лендинг по макету Figma.
- Использованы CSS Grid (для крупной сетки) и Flexbox (для компонентов).
- Реализован подход Mobile First с тремя контрольными точками: 375px, 768px, 1200px.
- Добавлено меню-гамбургер для мобильной версии (только вид, без JS).
- Добавлена форма обратной связи (имя, email, сообщение) с :hover и :focus.
- Добавлены плавные переходы (transition).

**Файлы:**
- `index.html` — структура страницы
- `style.css` — стили

**Как запустить:**
Открыть `index.html` в браузере или посмотреть на GitHub Pages:
https://toymyradova.github.io/web-course-2026/task2/
