# Задание 6 — Игра «Змейка» на Canvas

**Что сделано:**
- Реализована классическая «Змейка» на `<canvas>` 400×400.
- Сетка 20×20 клеток по 20px.
- Змейка из 3 сегментов, движется по стрелкам.
- Нельзя развернуться на 180° (проверка направления).
- Яблоко появляется в случайной свободной клетке.
- Съел яблоко → счёт +1, змейка длиннее на 1.
- Столкновение со стеной или хвостом → конец игры.
- Отображение счёта и рекорда.
- При конце: надпись «Игра окончена» + кнопка «Начать заново».
- Игровой цикл через `requestAnimationFrame`.
- Постоянная скорость через `deltaTime` (150мс на клетку).
- Логика (`update`) и отрисовка (`draw`) разделены.
- Код разбит на функции: `spawnApple`, `moveSnake`, `checkCollision`, `drawSnake` и др.

**Файлы:**
- `index.html`, `style.css`, `script.js`
