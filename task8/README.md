# Задание 8 — Zen-Money (учёт финансов)

**Что сделано:**
- Реализовано полноценное CRUD-приложение для учёта доходов и расходов.
- Для «сервера» используется `json-server` с файлом `db.json` (порт 3001).
- Форма добавления операции: сумма, тип (доход/расход), категория, дата, комментарий.
- При отправке формы выполняется `POST`-запрос на `/transactions`.
- Список всех операций загружается через `GET /transactions`.
- Реализовано удаление операции (`DELETE /transactions/:id`).
- Реализовано редактирование операции (форма переключается в режим правки, выполняется `PUT /transactions/:id`).
- Сверху отображается итоговая сводка: «Доходы, Расходы, Баланс». Баланс считается на основе всех загруженных операций.
- Все запросы написаны через `fetch`, `async/await` и обёрнуты в `try/catch`.

**Архитектура (ES-модули):**
- **`api.js`** — все функции работы с сервером (`getTransactions`, `addTransaction`, `deleteTransaction`, `updateTransaction`, `getCategories`).
- **`ui.js`** — функции отрисовки (рендер карточек операций, категорий, подсчёт баланса).
- **`main.js`** — точка входа, подписка на события, связка API и UI.

**Файлы:**
- `index.html` — разметка
- `style.css` — стили (тёмная тема)
- `db.json` — база данных для json-server
- `api.js` — работа с сервером
- `ui.js` — отрисовка интерфейса
- `main.js` — главный скрипт (точка входа)

**Как запустить локально:**
1. Установить json-server: `npm install -g json-server`
2. Запустить сервер в папке task8: `json-server --watch db.json --port 3001`
3. Открыть `index.html` через Live Server.
