# Задание 3 — Основы JS и DOM: Todo-list

**Что сделано:**
- Реализован интерактивный список задач на чистом JavaScript (без библиотек).
- Задачи хранятся в массиве объектов вида { id, text, completed }.
- Отрисовка списка происходит через функцию render(), которая перерисовывает список при любом изменении данных.
- Добавление задачи: через кнопку «Добавить» и по нажатию Enter.
- Валидация: пустая задача не добавляется, показывается предупреждение.
- У каждой задачи есть кнопка выполнения (зачёркивание через класс .completed) и кнопка удаления.
- Счётчик показывает: «Осталось: N, Выполнено: M».
- Фильтры: «Все», «Активные», «Завершённые» — скрывают ненужные задачи через display: none, не удаляя их из данных.
- Использованы методы массивов map, filter, forEach.
- События обрабатываются через addEventListener, без onclick в HTML.
- В консоли браузера нет ошибок.

**Файлы:**
- index.html — разметка;
- style.css — стили;
- script.js — логика.
