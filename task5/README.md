# Задание 5 — Игра «Симон говорит»

**Что сделано:**
- Реализована игра на память с 4 цветными кнопками.
- Компьютер показывает последовательность с задержками через `setTimeout`.
- Клики блокируются во время показа последовательности.
- После верного ввода — следующий уровень (последовательность длиннее на 1).
- Ошибка → конец игры, показывается достигнутый уровень.
- Все таймеры корректно очищаются при новой игре (нет «зависших» таймеров).
- Код разбит по паттерну **MVC**: логика, отрисовка и управление разделены.
- Нет глобальных переменных — все модули обёрнуты в IIFE.
- Реализован принцип **Open/Closed**: цвета кнопок и тайминги вынесены в конфиги.

**Файлы:**
- `index.html` — разметка
- `style.css` — стили
- `model.js` — Model (данные и логика игры)
- `view.js` — View (отрисовка и обработчики DOM)
- `controller.js` — Controller (связка Model и View)
