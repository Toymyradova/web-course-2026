# Задание 7 — Асинхронность: лента постов с бесконечным скроллом (MVC)

**Что сделано:**
- Реализована лента постов с загрузкой данных через `fetch` с API `jsonplaceholder.typicode.com/posts`.
- При загрузке страницы подгружается первая порция постов (10 штук).
- Каждый пост отображается карточкой: заголовок, текст, id автора.
- Реализован **бесконечный скролл** (за 200px до низа подгружается следующая порция).
- Подгрузка останавливается после исчерпания всех 100 постов (выводится сообщение «Больше постов нет»).
- Добавлено поле поиска с фильтрацией по подстроке в заголовке.
- Для поиска реализован **дебаунс** (300 мс) через `setTimeout` / `clearTimeout`.
- Пока идёт загрузка, показывается CSS-спиннер.
- Каждый `fetch` обёрнут в `try/catch`, при ошибке выводится сообщение.

**Архитектура (MVC):**
- **`model.js`** — хранит данные (все посты, отфильтрованные посты), выполняет `fetch`-запросы, управляет пагинацией и ошибками. Не знает о DOM.
- **`view.js`** — создаёт карточки постов в DOM, управляет спиннером, сообщениями об ошибках и конце ленты. Ловит ввод в поле поиска. Не знает о `fetch` и логике.
- **`controller.js`** — связывает Model и View. Слушает скролл, передаёт поисковый запрос в Model, отдаёт результат во View.

**Файлы:**
- `index.html`
- `style.css`
- `model.js`
- `view.js`
- `controller.js`
