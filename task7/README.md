# Задание 7 — Асинхронность: лента постов с бесконечным скроллом

**Что сделано:**
- Реализована лента постов с загрузкой данных через `fetch` с API `jsonplaceholder.typicode.com/posts`.
- При загрузке страницы подгружается первая порция постов (10 штук).
- Каждый пост отображается карточкой: заголовок, текст, id автора.
- Реализован бесконечный скролл: при прокрутке до конца подгружается следующая порция.
- Подгрузка останавливается после 100 постов.
- Добавлено поле поиска с фильтрацией по заголовку.
- Для поиска реализован дебаунс (300 мс).
- Пока идёт загрузка, показывается CSS-спиннер.
- Каждый `fetch` обёрнут в `try/catch`, при ошибке выводится сообщение.
- Код разбит на MVC: `model.js`, `view.js`, `controller.js`.
- Реализован счетчик загруженных постов и прогресс-бар.

**Файлы:**
- `index.html`
- `style.css`
- `model.js`
- `view.js`
- `controller.js`
