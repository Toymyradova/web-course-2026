# Задание 4 — Игра «Быки и коровы»

**Что сделано:**
- Реализована игра «Быки и коровы» на чистом JavaScript (без библиотек).
- Компьютер загадывает 4-значное число с неповторяющимися цифрами.
- Есть валидация ввода: ровно 4 цифры, все разные, только цифры.
- После каждой попытки показывается количество «быков» и «коров».
- История попыток хранится в массиве и рендерится через DOM.
- Есть счётчик попыток и проверка победы (4 быка).
- Кнопка «Новая игра» сбрасывает состояние без перезагрузки страницы.
- Логика разбита на отдельные функции: генерация, валидация, подсчёт.

**Файлы:**
- `index.html` — структура страницы
- `style.css` — стили
- `script.js` — логика игры

**Как запустить:**
Открыть `index.html` в браузере или посмотреть на GitHub Pages:
